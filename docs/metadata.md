# Metadata 字段说明

本页解释使用 BrainProject407 矩阵时需要的 metadata。公开仓库只提供字段说明和教程，不包含 metadata 表、逐人编号映射、文件清单或校验值。请从数据管理方的授权渠道取得与所用数据版本匹配的配套 metadata，并按工具参数显式指定本地文件。

下面的文件名用于说明各类来源记录，不表示这些文件已包含在仓库中。表格通常采用 UTF-8 TSV，首行为字段名，制表符分隔；具体文件名和交付格式以数据管理方提供的版本为准。空值表示来源未记录，不表示零或已确认不存在。

本页的数量和状态来自 **2026-10-10 检查快照**。2026-10-11 仅整理公开文档，没有重新检查实时数据目录。

## 数据集来源表

来源记录中的 `datasets.tsv` 一行对应一个数据集目录。

| 字段 | 含义 |
| --- | --- |
| `dataset_id` | 项目内部数据集目录编号，不是外部数据库登录号 |
| `dataset_name` | 本项目记录的可读名称 |
| `source_dataset` | 原处理流程使用的来源数据集名称 |
| `source_accession` | 上游数据集标识；空值表示未记录 |
| `source_version` | 来源版本或样本选择说明，不一定是正式发布版本号 |
| `participants` | 该次交付范围内被试数，不是上游完整数据集人数 |
| `matrix_files` | 该次交付范围内矩阵文件数 |

2026-10-10 快照覆盖八个数据集、588 名被试和588个 Shen268 矩阵，每人一个矩阵。选择说明中的数字不应直接当作本次交付人数；缺失版本也不应理解为最新版。数据集级来源对应关系见[仓库首页](../README.md)。

## 被试映射表

来源记录中的 `participants.tsv` 一行对应一个项目被试。数据管理方可另行提供去除不必要临床字段的映射表；公开仓库不提供这些记录。

| 字段 | 含义 |
| --- | --- |
| `project_subject_id` | 项目唯一被试编号，须按字符串保存并保留前导零 |
| `dataset_id` | 连接数据集来源表的外键 |
| `dataset_name` | 可读的数据集名称 |
| `source_subject_id` | 原数据集被试编号或替代索引，须结合 `source_id_type` 解释 |
| `source_id_type` | `original_dataset_id` 表示原数据集编号；`pseudonym` 表示去标识化替代索引 |
| `source_session` | 原处理会话标签，不保证等同于原始采集会话或采集日期 |
| `matrix_status` | 来源保留的矩阵状态，与 DTB 连接表生成状态独立 |
| `matrix_268` | 相对于数据根目录的 Shen268 矩阵路径 |
| `diagnosis` | 原表可能包含的诊断分组；矩阵读取及编号关联不依赖该列 |

项目编号在筛选、排序或新增记录后不应重排或复用。原始编号只能在所属数据集内解释；HCP、PPMI 等数字形式的编号也应当作字符串。D004 的来源编号是伪名，不能视为原始姓名或真实身份编号。真实身份对应关系不属于公开教程。

`source_session` 中的 `ses-baseline` 有时是处理适配标签，不能据此推断真实基线日期。匹配数据时应使用管理方提供的显式映射，不应根据文件名推断临床属性。

2026-10-10 快照的矩阵状态为580条 `candidate_pending_human_review` 和8条 `available_with_isolated_nodes`。前者不表示人工审核通过，后者表示来源保留了孤立节点状态。这两个数量与“8人已生成 DTB 连接表”属于不同统计，不能据此认定是同一批被试。

## 矩阵文件清单

来源记录中的 `files_manifest.tsv` 一行对应一个矩阵文件。授权配套包可能使用其他文件名，读取时应核对字段。

| 字段 | 含义 |
| --- | --- |
| `dataset_id` | 矩阵所属数据集 |
| `project_subject_id` | 与被试映射表关联的项目编号 |
| `atlas` | 图谱标识；2026-10-10 快照中均为 Shen268 |
| `rows`、`columns` | 记录的矩阵尺寸；该快照均为268 |
| `path` | 相对于数据根目录的 CSV 路径，应与被试表的 `matrix_268` 一致 |
| `sha256` | 来源清单记录的 CSV 文件字节 SHA-256 |

校验时对收到的原始 CSV 文件计算 SHA-256，再与授权清单比较。即使数值不变，重新保存 CSV 也可能改变换行、精度或编码，从而改变文件哈希。分析结果应另存，不应覆盖用于完整性核验的原文件。

该来源清单没有文件大小字段，也不覆盖额外的 DTB 二进制文件。哈希匹配只证明文件字节与清单相符，不代表影像质量或模型适用性已经审核通过。公开仓库不提供逐文件校验值。

## 脑区节点表

来源中的 `nodes_shen268.tsv` 规定矩阵行列顺序。必须取得与矩阵匹配的节点表，不能用另一个同名图谱的排序替代。

| 字段 | 含义 |
| --- | --- |
| `matrix_index_0based` | 从0开始的矩阵行列下标，Shen268 中范围为0至267 |
| `matrix_index_1based` | 从1开始的行列序号，范围为1至268 |
| `atlas_label` | 图谱标签值，通过节点表关联，不在一般情况下假设它等于行号 |
| `is_cortex` | `1` 为皮层，`0` 为非皮层，`not_in_canonical_map` 表示来源映射未提供该属性 |

2026-10-10 快照中，`is_cortex` 的计数为192个 `1`、25个 `0` 和51个 `not_in_canonical_map`。未知值不能自动当作非皮层，也不表示应删除节点。既有 DTB 输出使用整数 `-1` 表示未知皮层属性，原节点表保留字符串未知值。

来源另有 Shen217 固定子集映射，但2026-10-10 检查范围内没有 Shen217 矩阵。若后续获准使用该子集，须取得正式子集映射；不能直接截取 Shen268 的前217行。

## 原目录索引字段

来源 `catalog.csv` 是处理流程使用的索引。理解旧记录时，可按下表区分来源字段与公开映射字段；它不是本仓库附带的文件。

| 字段 | 含义 |
| --- | --- |
| `dataset`、`subject`、`session` | 原处理流程的数据集、被试及会话键，不能自动视为适合公开的标识 |
| `status` | 来源处理状态；须连同生成该状态的流程解释 |
| `structural_numeric_pass` | 原结构矩阵数值检查的布尔结果，不等于人工影像审核结论 |
| `csv_268`、`sha256_268` | Shen268 文件引用及其记录哈希 |
| `full_atlas_isolated_labels` | 来源记录的完整图谱孤立节点标签；应核对图谱标签与矩阵索引的区别 |
| `functional_errors` | 来源流程记录的功能相关错误信息；空值本身不能证明存在功能数据或已通过功能检查 |
| `source_bundle` | 内部来源包追溯信息，由数据管理方维护 |
| `project_subject_id`、`dataset_id` | 项目内关联键 |
| `public_source_subject_id` | 来源为可交付映射保留的编号，与被试表的 `source_subject_id` 关联 |
| `source_id_type` | 来源编号的类型，区分原数据集编号与伪名 |

2026-10-10 快照中，`structural_numeric_pass` 记录580个 True 和8个 False；公开文档整理没有重新运行该质控流程。字段名中的 `public` 也不能替代实际的数据访问或公开授权。

## DTB 状态与生成参数

取得授权连接表后，应同时取得对应生成记录。字段名以实际 manifest 为准，常见字段如下。

| 字段或字段组 | 含义 |
| --- | --- |
| `input`、`input_sha256` | 输入矩阵引用与输入字节哈希 |
| `reference`、`reference_sha256` | 参考生成代码及其哈希；单文件哈希不能完整描述运行环境 |
| `status` | 已有流程记录的状态，例如 `prepared`、`generated_pending_validation`、`validated` |
| `requested_scale`、`actual_neurons` | 请求的神经元规模与实际分配数量 |
| `regions`、`populations`、`blocks` | 脑区、神经元群体和输出计算块数量 |
| `degree`、`dtype`、`seed` | 入度参数、连接权重类型与随机种子 |
| `allocation` | 神经元分配、取整与最小群体数量规则 |
| `isolated_csv_rows_zero_based`、`isolated_policy` | 孤立脑区的零基下标及处理策略 |
| `unknown_cortex_csv_rows_zero_based`、`is_cortex_unknown_value` | 皮层属性未知的行下标及输出编码 |
| `csv_order` | 输入矩阵行列顺序的处理约定 |
| `g_ui`、`tao_ui` | 既有生成器记录的通道电导与时间常数参数，含义和单位须依照匹配的模型实现 |
| `estimated_table_bytes`、`actual_table_bytes` | 估算与验证时记录的连接表文件字节量 |
| `validation` | 既有验证器的逐块检查记录，例如神经元数、连接数和文件字节量 |

`validated` 表示生成验证流程已经记录该状态，不能扩展解释为源影像人工审核通过。文件存在性和字节大小检查也不等价于重新验证数组内容。具体算法和使用边界见 [DTB 教程](dtb_tables.md)。
