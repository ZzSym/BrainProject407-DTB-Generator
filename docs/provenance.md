# 文档来源与版本

本公开仓库提供 BrainProject407 的数据解释和处理教程。文档依据 **2026-10-10 对既有交付范围的只读检查**，于 **2026-10-11 整理为公开版本**。整理公开文档时没有重新访问或审计实时数据目录，文中汇总数量不构成持续更新的生成进度。

## 公开仓库与授权配套材料

公开仓库保存文字说明及通用读取教程，不包含研究矩阵、DTB 连接表、逐人编号映射、metadata TSV/JSON、逐文件路径清单或校验值。教程中的字段名和文件名用于解释数据格式，不表示相应材料已公开。

接收 `BP407-D001` 至 `BP407-D008` 数据目录的使用者，应通过数据管理方的授权渠道取得与该数据版本匹配的来源表、被试映射、节点顺序表和文件完整性清单。若使用已有 DTB 输出，还应取得其生成记录、代码版本与环境说明。

文档中对编号类型的说明不能替代逐人来源映射。特别是 D004 的来源编号为伪名，其真实身份对应关系不属于公开仓库。

## 历史检查的范围

2026-10-10 快照的指定范围包含八个数据集、588名被试、588个 Shen268 矩阵，以及8份已有 DTB 连接表。该范围内没有 Shen217 矩阵。早期说明中较宽泛的“同时保留 Shen268 与 Shen217”不能作为这八个交付目录实际内容的证明。

当次检查核对了项目编号唯一性、被试映射与矩阵路径关联、节点索引顺序，以及既有 DTB 输入哈希与矩阵清单记录的一致性；还核对了已有连接表预期文件的存在性与 block NPZ 的记录字节大小。

矩阵哈希取自原文件清单，当次没有重新读取全部矩阵计算哈希；已有 NPZ 数组和全文件哈希也未重新验证。文档整理没有新增影像人工复核，不能据此把原有质量状态改写为全部验收通过。

`validated` 是既有连接表生成流程记录的状态。文件存在、字节大小一致、矩阵数值检查通过、源影像人工审核通过以及科学用途适用，是不同层面的结论，应分别保留证据。

## 使用时记录版本

实际分析应记录数据管理方提供的交付版本、所用节点表与文件清单版本、本仓库 Git commit，以及实际读取的生成器和分析代码版本。若授权数据包晚于2026-10-10，应以该包配套记录及实际检查结果确定人数、矩阵数量和处理状态，不能直接沿用本文快照数量。

源记录中部分数据集缺少正式发布版本，部分 `source_version` 是样本选择说明。使用者应向数据管理方补充确认所需版本、正式引用和访问条款，而不是把空白版本当作最新发布。

后续新增或替换数据时，应保留已有项目编号，更新授权配套的来源、映射和文件清单，并记录实际检查日期。仅修改命名或编写说明不应覆盖历史质量状态。

本仓库的公开不授予原始数据或配套 metadata 的访问、再分发权限。各来源的授权与引用条件继续适用；仓库中的通用工具和教程不能替代这些条件。
